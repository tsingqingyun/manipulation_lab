# Public Demonstration Dataset

Run `scripts/lab_python.sh scripts/download_dataset.py` from the repository root. The default file is `data/low_dim_v15.hdf5`; `LAB_DATASET` selects another location. The official public Can PH v1.5 low-dimensional dataset contains 200 episodes and 23,207 steps. Download URL and SHA256 are fixed in the downloader. Data is excluded from Git and made read-only after verification. Do not modify the demonstrations or mix policy rollouts into this dataset.
